# Agenda Clínica

Sistema web de agendamento de consultas para uma clínica-escola.

Projeto fictício criado para a disciplina de Gerência de Projetos (UFCSPA, 2026/2) para demonstrar o uso do GitHub na gestão de projetos.

## Objetivo

Permitir que pacientes vejam os horários livres dos profissionais e marquem consultas online, e que a recepção consiga acompanhar e cancelar agendamentos.

## Funcionalidades planejadas

- Consulta de horários disponíveis por profissional
- Agendamento de consultas
- Cancelamento pela recepção
- Lembrete por e-mail 24h antes da consulta

## Como acompanhamos o projeto

- **Issues** para registrar tarefas, bugs e histórias de usuário
- **Projects** para organizar o trabalho em quadro, tabela e roadmap
- **Milestones** para as entregas MVP e Versão 1.0
